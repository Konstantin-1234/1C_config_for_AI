Корректировка знаний ИИ об 1С:

1. Для ИИ запрещено использовать инструкцию "Попытка".
Код должен быть написан таким образом, что бы не возникало ошибочных ситуаций.

2. Запрещается использовать проверки для сокрытия нарушений в логике кода.
Если при кодировании допущена логическая ошибка, пусть программа падает сразу.

3. У объектов типа Соответствие отсутствует метод СодержитКлюч() 
Проверку нужно осуществлять с помощью метода Получить() 
Пример корректной проверки наличия ключа в соответствии: 
	ПроверяемоеСоответствие = новый Соответствие(); 
	...;
	Если  ПроверяемоеСоответствие.Получить(Ключ) <> Неопределено Тогда
		...;
	КонецЕсли; 

4. Использование цикла "Для" с шагом отличным от 1.
Для циклов "Для" в 1С отсутвет атрибут "Шаг", перебор всегда осуществляется от меньшего к большему с шагом 1.
Пример корректного перебора массива с конца к началу:
	ПервоначальноеКоличествоЭлементов = Массив.Количество(); 
	Для Итератор=1 по ПервоначальноеКоличествоЭлементов   Цикл
		ЭлементМассива = Массив[ПервоначальноеКоличествоЭлементов - Итератор];
	КонецЦикла; 

5. Удаление из таблицы значений.
Из таблицы значений удалять элементы нужно "с конца", иначе удаление будет происходить через одну запись.
Пример кода с корректным удалением из таблицы значений: 
	ПервоначальноеКоличествоЭлементов = ТабличнаяЧасть.Количество(); 
	Для Итератор=1 по ПервоначальноеКоличествоЭлементов   Цикл
		УдаляемыйЭлемент = ТабличнаяЧасть[ПервоначальноеКоличествоЭлементов - Итератор];
		ТабличнаяЧасть.Удалить(УдаляемыйЭлемент); 
	КонецЦикла; 

6. В 1С 8.3. отсутствует метод УзнатьТип(), нужно использовать метод ТипЗнч()
Пример:
	Если ТипЗнч ( ТекОбъект ) = Тип ( "СправочникСсылка.Номенклатура" ) Тогда
		. . .
	КонецЕсли ;

7. В 1С 8.3. отсутствует метод СтрНачинаетсяС(), нужно использовать метод Лев(Left)
Пример:
	ИнициалИмени = Лев ( Сотрудник . Имя , 1 );
	ИнициалОтчества = Лев ( Сотрудник . Отчество , 1 );
	ФамилияИнициалы = Сотрудник . Фамилия + " " + ИнициалИмени + "." + ИнициалОтчества + "." ;
