Корректировка знаний ИИ о платформе «1С:Предприятие 8.3»:

1. Запрет на использование конструкции «Попытка».
Код должен быть написан так, чтобы исключать возникновение ошибочных ситуаций.

2. Запрет на сокрытие логических ошибок.
Не следует использовать проверки для маскировки нарушений логики. При наличии логической ошибки выполнение программы должно быть прервано.

3. Проверка ключа в объекте «Соответствие».
У объекта «Соответствие» отсутствует метод СодержитКлюч(). Проверку наличия ключа необходимо осуществлять через метод Получить().
Пример корректной проверки:
ПроверяемоеСоответствие = Новый Соответствие();
Если ПроверяемоеСоответствие.Получить(Ключ) <> Неопределено Тогда
    Значение = ПроверяемоеСоответствие.Получить(Ключ);
КонецЕсли;

4. Особенности цикла «Для».
В языке 1С цикл «Для» не имеет параметра «Шаг». Перебор всегда осуществляется от меньшего значения к большему с шагом 1.
Пример корректного перебора массива в обратном порядке:
КоличествоЭлементов = Массив.Количество();
Для Итератор = 1 По КоличествоЭлементов Цикл
    ЭлементМассива = Массив[КоличествоЭлементов - Итератор];
КонецЦикла;

5. Удаление элементов из «ТаблицыЗначений».
Удаление элементов необходимо производить в обратном порядке, чтобы избежать смещения индексов и пропуска записей. Индексация в «ТаблицеЗначений» начинается с 1.
Пример корректного удаления:
КоличествоЭлементов = ТабличнаяЧасть.Количество();
Для Итератор = 1 По КоличествоЭлементов Цикл
    Индекс = КоличествоЭлементов - Итератор + 1;
    ТабличнаяЧасть.Удалить(Индекс);
КонецЦикла;

6. Определение типа значения.
В языке 1С отсутствует функция УзнатьТип(). Для определения типа значения необходимо использовать функцию ТипЗнч().
Пример:
Если ТипЗнч(ТекОбъект) = Тип("СправочникСсылка.Номенклатура") Тогда
    // Обработка
КонецЕсли;
